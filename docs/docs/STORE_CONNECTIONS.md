# External Store Connections

## Purpose

This document defines how Aurora connects creators with external commerce platforms while keeping the creator journey simple, guided, and organized.

## Supported Store Platforms

Initial platforms:

- Shopify
- Etsy
- Future marketplace integrations

## Connection Goals

Aurora should help creators:

- Connect existing storefronts
- Manage products across platforms
- Track store progress
- Reduce technical barriers
- Keep the creator focused on building

## Aurora Role

Aurora acts as the guide and organizer. External platforms handle storefront operations, while Aurora helps creators move from idea to execution.
